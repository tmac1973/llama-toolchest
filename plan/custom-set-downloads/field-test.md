## Notes

1. **Mixed set with Z-Image, not Ming.** The plan named the Ming diffusion model as the local file. Every Ming file is already on disk and its repo has one LLM quant only, so a Ming set would download nothing. Z-Image Turbo let the set mix a path, a reused link and a real download.
2. **Resume is not needed after an edit.** An edit starts the downloads it needs itself (and here completed the set at once, as the file was on disk). *Resume* then answers HTTP 409. The tooltip and the docs (`docs/guides/generation.md`, wrong-file paragraph) say "Edit the set to choose another file, then press Resume". The wording should drop "then press Resume".
3. **Delete leaves empty repo folders.** After the deletes, `gen-models/stabilityai--sd-turbo`, `black-forest-labs--FLUX.2-klein-4B` and `meta-llama--Llama-3.2-1B` (the failed gated download) stayed as empty folders. They were removed by hand.
4. **Gated repos fail at download, not at Add set.** The plan expected the #657 message in the Browse dialog. Hugging Face lists a gated repo's files and gives its commit to anyone, so both Browse and *Add set* succeed, and the error shows on the row. *Add set* could ask for the file's headers first and refuse a gated file before it saves the set.
