            Measure  first?
        

        
This instance has not been measured yet. Before it can start, llama-toolchest needs to know how much GPU memory it uses, so it can keep that much free for it.

        
Measuring runs one test generation with nothing else on GPU , records the most memory it used, and reserves that plus 10%. This takes from under a minute to several minutes. The instance then starts by itself.

        
Other image and music instances on that GPU must be stopped first. You can also measure again later with the Measure button.

        

            
            
        

    



    

        

            
            Measure 
        

        
Measuring makes one test image and one test edit with nothing else on GPU . It records the most memory they used and reserves that plus 10%.

        
Each image in an edit uses more memory and time. The instance then takes edits with up to the number of images you choose here. Edits with more images are refused.

        
        

        

            
            
        

    



    

        

            
            Measure 
        

        
Measuring makes one test video with nothing else on GPU , records the most memory it used, and reserves that plus 10% (no more than the card can give it). The instance then makes videos up to the size you choose here; larger requests are refused.
