About these charts
  • Scatter is the plain reading: one parameter against one measurement, one point per run. Use it when a job swept a single parameter.
  • Leaderboard is the direct answer to "which run won": every run as a bar, sorted best-first, with its value on the bar. Start here.
  • Heatmap is usually the fastest way to read a two-parameter sweep. Every cell carries its number, so you compare values by reading them rather than by judging shades.
  • Faceted heatmaps handle a third parameter: one heatmap panel per value of it, all sharing a single colour scale so panels can be compared directly. The chart for "several quants, each swept over batch and micro-batch".
  • Pareto plots prompt speed against generation speed when the two pull in different directions. Up and right is better; the ringed points are the frontier — configurations nothing else beats on both.
  • Parallel coordinates draws every run as a line crossing one axis per parameter and measurement. Drag along an axis to keep only the lines through that band — the tool for "what do my fastest runs have in common?". This is the one chart without hover.
  • 3D surface shows the same data as a landscape. It makes ridges and slopes obvious, but exact values are hard to read off it — parts of the surface hide other parts. Drag to rotate.
  • 3D scatter keeps every run as its own point, so nothing is interpolated. Useful when the sweep grid has gaps.
  • When runs from more than one configuration land on the same heatmap cell — a parameter not on the axes varies — the cell shows the best value and a note above the chart says how many cells did.
  • Hover any point for that run's full configuration. Every chart has a toolbar for zoom, pan and saving a PNG.
