About these charts
  • Scatter is the plain reading: one parameter against one measurement, one point per run. Use it when a job swept a single parameter.
  • Heatmap is usually the fastest way to read a two-parameter sweep. Every cell carries its number, so you compare values by reading them rather than by judging shades.
  • 3D surface shows the same data as a landscape. It makes ridges and slopes obvious, but exact values are hard to read off it — parts of the surface hide other parts. Drag to rotate.
  • 3D scatter keeps every run as its own point, so nothing is interpolated. Useful when the sweep grid has gaps.
  • Hover any point for that run's full configuration. Every chart has a toolbar for zoom, pan and saving a PNG.
