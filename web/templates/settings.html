Backup & Restore

Backs up configuration — settings, runtime environment, saved build flag sets, and per-model launch configs — not models, builds, or benchmark history. Model configs are keyed by HuggingFace identity, so a backup restores onto another server; configs for models not installed there wait as pending and attach automatically when the model is downloaded.

Startup

If enabled, the inference server starts automatically when the container launches, using the currently-selected build and model configs.

Generation backends

Lets llama-toolchest also run image generation (stable-diffusion.cpp) and music generation (acestep.cpp) next to llama-server. While this is off, nothing about them is shown or run.

{{if .GenerationEnabled}}

When an LLM and a backend do not both fit on a GPU, the newest request gets it: idle backends are stopped for a chat request (only as many as needed, and never one locked on the Server page), and idle LLMs are unloaded for an image or music job. A stopped backend starts again by itself when its next job arrives. Running jobs and chat replies always finish first. Each switch reloads a model, so expect a wait of seconds to a minute.

Only with the switch above on. Takes effect the next time the router starts (Server page → Restart).

{{end}} {{if and .GenerationEnabled (not .GenPortsPublished)}}

Web UI ports are not published, so the backends' own web pages cannot be opened. The image and music APIs still work. To open the web pages, run setup.sh install again and answer yes to "Publish ports for generation backend web UIs?".

{{end}}
Backend ports ({{.GenPortStart}}–{{.GenPortEnd}})

Each backend instance keeps its own port from this range for as long as it exists, and its built-in web UI is reached on that port. Stopped instances keep their ports too, so the number of ports is the most instances you can create.

{{if .InContainer}}

Inside a container the range is fixed at {{.GenPortStart}}–{{.GenPortEnd}}, the ports the container publishes. To change the number of ports, or the ports used on the host, run setup.sh install again.

{{end}}

Server URL

Base URL used for dashboard links (Chat UI, API endpoint). Defaults to http://localhost:3000. If you access this server from other machines, change this to an externally resolvable IP or hostname (e.g. http://192.168.1.50:3000).
